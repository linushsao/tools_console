# tools_console 外掛工具規範

## 1. 檔案位置與掃描規則
- 外掛檔案放置於 `plugins/` 目錄下，副檔名須為 `.py`
- 檔名以 `_` 開頭者（如 `_archive_common.py`）會被掃描器**略過**，可用於放共用輔助函式
- 每個外掛檔案對應**一個**指令（`__plugin_command__`），一檔一指令
- 程式啟動時自動掃描；執行期間可用 `RELOAD_PLUG` 指令重新掃描

## 2. 外掛必要欄位
```python
__plugin_command__     = "XX"       # 觸發指令（會自動轉大寫），須唯一
__plugin_name__         = "顯示名稱"  # PLUG 列表顯示用
__plugin_description__  = "功能描述"  # PLUG 列表顯示用
__plugin_usage__        = "用法說明"  # PLUG 列表顯示用（選填）
```

## 3. 必要進入點
```python
def run(fm, args):
    """指令執行邏輯，fm 為 FileManager 實例，args 為指令後的參數列表"""
    ...
```
- 若定義 `main(fm, args)` 亦可作為替代進入點（相容舊版寫法）

## 4. 選用 Hook
```python
def on_load(fm):
    """外掛載入時呼叫一次（程式啟動或 RELOAD_PLUG 時），用於相依套件檢查與降級提示"""
    ...
```
- 外掛應**自行**檢查相依套件是否安裝，並在 `on_load` 印出降級提示，不應由主程式判斷

## 5. 常用 fm 介面
| 屬性/方法 | 說明 |
|---|---|
| `fm.selected_items` | 目前已選取的相對路徑集合 |
| `fm.current_path` / `fm.work_path` | 目前瀏覽路徑 / 專案根目錄 |
| `fm.conf_dir` | 設定與暫存檔存放目錄 |
| `fm.save_config()` | 將設定寫回 config.json |
| `fm.scan_directory()` | 重新掃描目前目錄並刷新畫面 |

## 6. 相依套件處理原則
- 外掛自行 `try/except ImportError`，缺少套件時降級提示，不可讓主程式崩潰
- 範例：`plugins/pdf_export.py` 對 `fitz`、`plugins/patch_apply.py` 對 `pyperclip`

## 7. 現有外掛清單
| 指令 | 檔案 | 功能 |
|---|---|---|
| A | archive_pack.py | 打包選取檔案為 JSON |
| ZIP | archive_zip.py | 壓縮選取檔案為 ZIP |
| UA | archive_unpack.py | 解包 JSON 還原檔案結構 |
| PDF | pdf_export.py | PDF 轉換（座標過濾去行號） |
| PCH | patch_apply.py | 套用補丁（剪貼簿/目錄搜尋） |
| PA | pattern_search.py | 已選取檔案內容搜尋 |
| VC | version_control.py | 版本標籤更新 |

## 8. 保留於核心（不建議外掛化）
目錄掃描、翻頁、選取、刪除、忽略規則、指令歷史、外掛管理本身（PLUG/RELOAD_PLUG）、設定切換（CONF）— 屬核心狀態或框架層，與其他功能高度耦合。

## 9. 範例外掛程式碼

### 9.1 最小範例（含 on_load 相依檢查）
```python
# ==============================================================================
# plugins/hello_demo.py
# 外掛：範例外掛，示範最小可行結構
# ==============================================================================

__plugin_command__ = "HELLO"
__plugin_name__ = "範例外掛"
__plugin_description__ = "示範外掛最小結構，印出選取檔案數量"
__plugin_usage__ = "HELLO  -> 印出目前選取的檔案數量"

try:
    import somelib  # 假設的相依套件
    SOME_SUPPORT = True
except ImportError:
    SOME_SUPPORT = False


def on_load(fm):
    """外掛載入時呼叫一次，用於相依檢查與降級提示"""
    if not SOME_SUPPORT:
        print("⚠️ [HELLO 外掛] 未安裝 somelib，部分功能將無法使用")


def run(fm, args):
    """指令主邏輯，fm 為 FileManager 實例，args 為指令後的參數列表"""
    print(f"目前選取了 {len(fm.selected_items)} 個項目")
    if args:
        print(f"收到參數: {args}")
    input("按 Enter 繼續...")
```

### 9.2 實務範例（PA 內容搜尋外掛，摘自 plugins/pattern_search.py）
```python
import os

__plugin_command__ = "PA"
__plugin_name__ = "內容搜尋"
__plugin_description__ = "在已選取檔案中搜尋特定內容"
__plugin_usage__ = "PA <pattern>  -> 在目前選取的檔案中搜尋關鍵字"


def run(fm, args):
    if not args:
        print("❌ 請輸入要搜尋的 Pattern"); input(); return
    if not fm.selected_items:
        print("❌ 未選取任何檔案"); input(); return

    pattern = " ".join(args)
    found_list = []
    for rel in sorted(list(fm.selected_items)):
        full_path = os.path.join(fm.work_path, rel)
        if not os.path.isfile(full_path): continue
        try:
            with open(full_path, 'r', encoding='utf-8', errors='ignore') as f:
                if pattern in f.read():
                    found_list.append(rel)
        except Exception:
            pass

    if found_list:
        for p in found_list: print(f" [MATCH] {p}")
    else:
        print(f"❌ 未找到關鍵字: '{pattern}'")
    input("\n按 Enter 繼續...")
```

## 10. 新外掛程式碼模板（可直接複製使用）
```python

# plugins/<plugin_file_name>.py
# 外掛：<請填寫功能簡述>
# ==============================================================================

__plugin_usage__ = "XXX <參數>  -> 用法說明"

    DEP_SUPPORT = False

    """[選用] 外掛載入時呼叫一次（程式啟動 / RELOAD_PLUG 時），用於相依檢查與降級提示"""

        print("⚠️ [XXX 外掛] 未安裝 some_dependency，部分功能將無法使用 (pip install some_dependency)")

    args : 指令後面的參數列表（例如輸入 "XXX foo bar" 則 args = ["foo", "bar"]）
    """
    if not fm.selected_items:
        print("❌ 未選取任何檔案")
        input()
        return

    # TODO: 在此實作外掛邏輯

    input("按 Enter 繼續...")
```
**使用步驟：** 複製上方模板另存為 `plugins/<檔名>.py` → 填入 `__plugin_command__` 等欄位 → 於 `run()` 實作邏輯 → 執行 `RELOAD_PLUG` 或重啟程式即可載入。
